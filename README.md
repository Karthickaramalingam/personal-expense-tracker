
# Personal Expense Tracker

A command-line application built with Python
to record and manage personal expenses.

## Features
- Add expenses
- Validate user input
- Store expenses in JSON
- View saved expenses
- Calculate total spending
- Handle file and JSON errors

## Technologies
- Python
- JSON
- pathlib
- Exception handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `python main.py`.

## Future Improvements
- Edit and delete expenses
